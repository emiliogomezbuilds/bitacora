## Session 2 — Build

- Scaffolded Next.js 16 App Router (TypeScript, Tailwind v4, ESLint, no src-dir). `shadcn` CLI failed twice (bad `-b neutral` flag, then hung past timeout) — abandoned it and hand-wrote `lib/utils.ts` + `components/ui/{button,card,badge}.tsx` plus the CSS custom properties Tailwind v4's `@theme inline` needs, matching shadcn's own conventions.
- Wrote `supabase/schema.sql`: `associations` (one per admin, owner_id = auth.uid()), `units`, `telemetry_pings` (no driver-identity field anywhere, by design), and `share_consents` — the load-bearing table for the shadow clause. `share_consents` has a second RLS policy letting *any* authenticated user read rows where `consented = true`; that single policy is the entire mechanism for "nothing reaches Gov before the association has already seen and approved it," and it's revocable (flip `consented` back to false, the row disappears from Gov's view immediately).
- ML/Dragon-Stack component is deliberately simple and named honestly in `lib/status.ts`: a unit is "sin señal" only once it's gone quiet for more than 2x its own declared expected ping interval. No model, no predictive claim — matches the packet's own description and Condition 6 (no unproven-safety-improvement claims).
- Built: `/login` (Google OAuth), `/auth/callback`, `/dashboard` (auto-creates the admin's association + seeds 12 units on first visit, Leaflet map, per-unit status, "simular ronda de avisos" button that deliberately skips ~10% of units so there's always a real sin-señal example), `/consent` (preview of the exact aggregate snapshot before authorizing, toggle to authorize/revoke), `/gov` (simulated government/insurer viewer — reads only `share_consents` where `consented = true`, nothing else).
- `@types/leaflet` was missing after `npm install react-leaflet leaflet` — without it, `tsc` silently widened every react-leaflet prop type and threw false "Property does not exist" errors on `center`, `attribution`, `radius`. Installed `@types/leaflet` as a devDependency; `tsc --noEmit` and `eslint` both pass clean now.
- `npm run build` fails in this sandbox only on the Geist Google Font fetch (no outbound network here) — not a code error; Vercel's build servers reach fonts.googleapis.com fine, this is the same non-issue seen in prior weeks' sandboxed builds.
